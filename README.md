# LANA 3

Projekt LANA 3.

LANA 3 je uređajno i vendorski neovisan multiplatformski sustav. Android je prvi fizički klijent i testna platforma, a ne granica proizvoda. Zajednička jezgra mora ostati prenosiva na iOS, desktop, web i buduće platforme putem jasno odvojenih adaptera.
